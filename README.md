# Mayur Joshi — Portfolio

Personal portfolio site for Mayur Pravin Joshi — full-stack software developer.

Built with:

- [TanStack Start](https://tanstack.com/start) (React + SSR)
- TypeScript
- Tailwind CSS
- shadcn/ui-derived component primitives

## Development

Requires Node.js 20+.

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
npm run preview
```

The production build targets Cloudflare (via Nitro's `cloudflare-module` preset) — adjust the preset in `vite.config.ts` if you're deploying elsewhere.
